# PerfSentinelHub lab validation ledger
# format: <version>\t<lab_commit_sha>\t<YYYY-MM-DD>\t<PASS|FAIL>
# Append-only. Lines are produced by `scripts/record-validation.sh vX.Y.Z PASS` in the perf-sentinel-simulation-lab repo.
#
# The lab exercises the Hub through six scenarios: hub-ingestion, hub-derived-status,
# hub-lineage-mutation, hub-retention-purge, hub-source-reachability and
# hub-plugin-contract. They run a real Hub image against a real daemon, so a
# validation names the Hub commit it was built from, not only the version.
#
# The first entry validates a version that has never been published: the whole
# point of the gate is to assert the lab saw the build before the tag exists.
